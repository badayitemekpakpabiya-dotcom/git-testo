# CV dossier consolidé

Ce dossier contient les éléments d’un même projet CV / website réuni en une version unique :

- `KOKO.html` : générateur de CV en HTML/JS avec formulaire, aperçu, export JSON/CSV et impression.
- `cv-website.zip` et `cv-website2.zip` : versions d’un site web CV Flask avec compte utilisateur, profil public, upload de CV et liens partageables.
- `emploi-header.svg` : visuel de fond utilisé pour les éléments de branding.
- `index.html` : version consolidée, prête à être utilisée comme page principale finalisée.

## Objectif de la fusion

Le dossier a été regroupé en une présentation unique qui réunit :

1. La structure d’un CV moderne et lisible.
2. Les fonctionnalités d’un site web de CV accessible en ligne.
3. Les ressources visuelles et techniques déjà produites.

## Fichiers utiles

- `index.html` : point d’entrée visuel principal.
- `KOKO.html` : version de travail détaillée du générateur CV.
- `cv-website.zip` : source de l’application web.

## Points clés

- Le générateur de CV propose un formulaire d’édition, un aperçu côté droit et des exports utiles.
- L’application web propose la gestion de profils publics, de comptes et de CV uploadés.
- La version consolidée met en avant ces informations dans une interface claire et cohérente.
